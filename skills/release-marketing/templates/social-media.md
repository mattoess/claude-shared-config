# Social Media Templates

## LinkedIn Post

```
[HOOK — bold claim, surprising stat, or pattern interrupt]

[PROBLEM — 1-2 sentences on the pain point this solves]

[SOLUTION — what we shipped and why it matters, with specifics]

[PROOF — metric, customer quote, or concrete example]

[CTA — question for engagement or link to try it]

#AIinSales #B2BSales #SalesEnablement #RevenueGrowth #SalesTech
```

### LinkedIn Voice Guidelines
- Write as Matt Oess (founder perspective)
- First person where natural, but focus on the customer's problem
- No corporate speak — conversational, direct, occasionally provocative
- Short paragraphs (1-2 sentences max per paragraph)
- Use line breaks liberally for readability on mobile
- Specific > vague: "2-minute prep" not "faster prep"

## Twitter/X Thread

```
1/ [HOOK — bold claim under 280 chars, no hashtags on first tweet]

2/ [CONTEXT — why this matters, what problem it solves]

3/ [WHAT WE BUILT — specific feature with concrete benefit]

4/ [PROOF OR EXAMPLE — how it works in practice]

5/ [CTA — try it / link / question]
🔗 revenuegrowthagent.com
```

### Twitter Voice Guidelines
- Punchier than LinkedIn — every word earns its place
- Thread tweets should be readable standalone (someone might only see one)
- Use numbers and specifics to stop the scroll
- No emoji overload — one per tweet max, if any
- Link only in last tweet

---

## Email Snippet

```
Subject: [UNDER 50 CHARS — curiosity-driven, specific]
Preview: [UNDER 90 CHARS — extends the subject, doesn't repeat it]

Hi [NAME],

[PROBLEM — 1 sentence, make them nod]

[SOLUTION — what's new and how it helps them specifically]

[CTA — single clear action, link to page or demo]

— Matt

P.S. [Optional urgency or secondary hook]
```

### Email Voice Guidelines
- Subject line: curiosity or specificity, never both
- One CTA per email — don't split attention
- Write like you're emailing a colleague, not broadcasting
- P.S. line is optional but high-impact when used well
